# Course Storyboard Prompt

Paste everything inside the code block below to any LLM to get a ready-to-use course storyboard.
The LLM will pick a topic and write all the content — you use the storyboard to build the course in the demo app.

---

```
You are an expert instructional designer. Your job is to create a complete course storyboard that I will use to build a demo e-learning course.

Pick any engaging professional topic (e.g. "Effective Communication at Work", "Cybersecurity Basics", "Introduction to Design Thinking", "Workplace Mental Health", "Agile Project Management") — choose whatever makes for the richest demo content.

---

## YOUR ROLE

Generate a full storyboard document. I will read each page of the storyboard and manually enter the content into the e-learning authoring tool. Your job is to write all the actual content — text, questions, answers, labels, explanations — so I have everything I need without having to think of content myself.

The course uses 19 page templates. Use each one exactly once in the order listed below.
For every page, write the complete content ready to copy-paste into the tool.

---

## OUTPUT FORMAT

Write the storyboard as a clean document with one section per page.
Use this exact structure for each page:

---
### PAGE [N] — [PAGE TITLE]
**Template:** [Template Name]
**Purpose:** [One sentence — what the learner does or learns on this page]

[Then write the actual content for that template as described in the template guide below]
---

Write real, detailed, professional content. Do not use placeholder text like "Lorem ipsum"
or "[Insert text here]". Every word should be final, publication-ready course content.

---

## THE 19 TEMPLATES — WHAT TO WRITE FOR EACH

### Template: Course Menu
Write:
- Course title and subtitle
- A list of 5–6 menu items with label and one-line description each
  (these should match the major phases of your course)

### Template: Text Content
Write:
- A full introduction page (400–600 words) covering:
  why this topic matters, who the course is for, what they will be able to do
  by the end, and a brief overview of the course structure.

### Template: Tabs
Write:
- 4 tabs with a title and full body text (150–200 words each)
- Tabs should cover distinct sub-topics or perspectives on the same theme

### Template: Accordion
Write:
- 5 collapsible sections, each with a heading and 100–150 word body
- Good for FAQs, common misconceptions, or a glossary of key terms

### Template: Text with Media
Write:
- A section title
- 200–250 words of body text
- A caption/alt text for the image (describe what a suitable image would show)
- Specify layout: image-left or image-right

### Template: Image Hotspots
Write:
- Describe the image (what it shows — a diagram, a workplace scene, a process chart, etc.)
- 5–6 hotspots, each with:
  - A short label (2–4 words)
  - A popup description (2–3 sentences explaining that element)
  - Approximate position on the image (e.g. "top-left", "centre", "bottom-right")

### Template: Flip Cards
Write:
- 6 flip cards, each with:
  - Front: a term, concept, or question (max 8 words)
  - Back: the definition, explanation, or answer (2–3 sentences)

### Template: Carousel
Write:
- 5 slides, each with:
  - A slide title (4–6 words)
  - Slide body (100–120 words of content — a key point, step, or insight)

### Template: Drag & Drop Sort
Write:
- An instruction line (e.g. "Arrange these steps in the correct order")
- 5–6 items to sort, written as the correct order
  (label each with its correct position number starting from 1)

### Template: Knowledge Check (mid-course formative quiz)
Write:
- Title: "Knowledge Check"
- 4 questions testing concepts covered in pages 1–9:
  - 2 multiple-choice questions (4 options each, mark the correct one)
  - 1 true/false question
  - 1 multiple-choice question
- For each question: question text, all options, correct answer marked, brief explanation

### Template: Multiple Choice (MCQ)
Write:
- 1 standalone MCQ question (4 options, 1 correct)
- Full explanation paragraph

### Template: Multiple Select
Write:
- 1 standalone "select all that apply" question (4–5 options, 2–3 correct)
- Full explanation paragraph

### Template: True / False
Write:
- 1 standalone true/false statement
- Whether it is TRUE or FALSE
- Full explanation (2–3 sentences)

### Template: Fill in the Blanks
Write:
- A sentence or short paragraph with 3 blanks marked as [BLANK]
  (rewrite it below showing where the blanks go)
- The correct word/phrase for each blank
- 1–2 acceptable alternative spellings per blank

### Template: Matching
Write:
- An instruction line
- 5 pairs to match (left term → right definition/match)
- The correct pairing for each

### Template: Summary & Takeaways
Write:
- Title and a 1–2 sentence intro
- 6 key takeaway bullet points (1–2 sentences each, mix of normal and highlighted)
- A closing remark (1–2 sentences)
- A next steps line directing learners to the final assessment

### Template: Final Assessment
Write:
- Title, instructions, passing score (80%)
- 8 questions covering the whole course:
  - 5 multiple-choice (4 options each, 1 correct)
  - 2 true/false
  - 1 multiple-choice with explanation
- For each question: question text, all options, correct answer marked, explanation

### Template: Completion Certificate
Write:
- Course title (full formal name)
- Organisation name
- Certificate title
- Completion message text (1 formal sentence)

---

## RULES

1. Pick an engaging professional topic yourself. State the topic clearly at the top.
2. Use all 19 templates in the order listed above.
3. All content must be coherent, consistent, and on-topic throughout.
4. Write at the level of a real published course — professional, clear, jargon-explained.
5. Do not truncate or summarise. Write the full content for every single page.
6. End with a summary table:

| Page # | Template | Page Title |
|--------|----------|------------|
showing all 19 rows.
```
