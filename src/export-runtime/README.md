# Export Runtime (Phase 0 Scaffold)

This folder contains the canonical frontend-owned SCORM export runtime source.

Phase 0 goals covered by this scaffold:
- typed payload contracts
- registry-driven renderer dispatch
- fallback renderer for unsupported component types
- baseline renderers for `content-text`/`content`, `tabs`, and `mcq`
- base styles and unit tests for registry behavior

This runtime is intentionally minimal and designed to be expanded category-by-category.
